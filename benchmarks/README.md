# Benchmarks — LLM comparison harness

Member B's tooling for the report's LLM comparison. It runs the **same coding
tasks through the full Golu agent** on several models and measures how well and
how efficiently each one completes them.

## Files

| File | What it is |
|---|---|
| `tasks.py` | The task set: prompt + fixture + objective verify command per task |
| `fixtures/` | Small broken/incomplete projects the agent must fix (copied fresh per run) |
| `run_comparison.py` | Runs every (model x task), verifies pass/fail, logs one JSON line per run |
| `aggregate.py` | Turns the results log into Markdown tables for the report |
| `results.jsonl` | Generated by a run. Keep the final one if you want the report numbers reproducible in the repo; otherwise add it to `.gitignore`. |

## Requirements

- A working Golu: `GROQ_API_KEY` in `.env` for Groq (or Ollama running for a local model)
- **Node** (the filesystem MCP server starts with `npx`)
- **pytest** on PATH: `pip install pytest`  (the verify step runs `python -m pytest`)

No RAG index is needed — the tasks only use the filesystem server and
`run_shell`, and Golu skips any MCP server that fails to start.

## Run it

```bash
# From the repo root, venv active:
python -m benchmarks.run_comparison \
    --models groq:openai/gpt-oss-120b groq:openai/gpt-oss-20b \
    --out benchmarks/results.jsonl

python -m benchmarks.aggregate benchmarks/results.jsonl
```

Useful flags:

- `--tasks bugfix` — run a subset of tasks
- `--models ... ollama:qwen2.5-coder:7b` — add a local model (needs Ollama)
- `--max-steps 25` — agent step cap per task
- `--agent-timeout 600` — seconds before a single run is killed

## How a run works

For each model and task, the runner copies the fixture to a temp folder, runs
`python -m golu --provider ... --model ... --mode auto -p "<task prompt>"
--project <temp> --stats-file <temp>`, then runs the task's verify command in
that folder. Success is the verify command's exit code — the model's own claim
of success is never trusted. Each run appends one record to the results file
with the model, task, pass/fail, and all of Golu's stats.

The write-up lives in [`../docs/llm-comparison.md`](../docs/llm-comparison.md).
